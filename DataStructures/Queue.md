# Queue（佇列）資料結構詳解

> **延伸閱讀**：圖的廣度優先走訪，請見 [BFS 演算法詳解](../Graph/BFS.md)。  
> **與優先順序有關的「出隊」**（例如永遠先取最小值）請見 [Heap](Heap.md) 的 **Priority Queue**。

---

## 一、定義與特性

**Queue（佇列）** 是一種 **先進先出（FIFO, First-In-First-Out）** 的線性結構。元素從 **後端（rear）** 入隊（enqueue），從 **前端（front）** 出隊（dequeue）。

核心特性：

| 特性 | 說明 |
|------|------|
| **FIFO** | 最早入隊者最先離開 |
| **實作** | 陣列＋頭尾指標，或鏈結串列 |

---

## 二、核心操作與複雜度

| 操作 | 時間 | 說明 |
|------|------|------|
| enqueue | O(1) | 後端加入 |
| dequeue | O(1) | 前端移除（陣列實作需注意假溢出，常用環形緩衝） |
| 觀察前端 | O(1) | |

### Deque（雙端佇列）

可在 **兩端** 皆 O(1) 加入／移除。適合「從兩端滑動」的題型（如單調 deque 維護窗口最值）。與一般 Queue 的差別在於操作自由度更高。

### Queue vs Heap（優先佇列）

| 結構 | 出隊順序 |
|------|----------|
| **一般 Queue** | 嚴格 FIFO，與鍵值大小無關 |
| **Priority Queue（堆實作）** | 依優先度（如最小／最大）出隊，非純先進先出 |

---

## 三、單調佇列與單調雙端佇列（Monotonic Queue / Monotonic Deque）

**單調佇列**在競程與面試中多指：**用雙端佇列（deque）維護候選元素的下標或值**，使佇列在 **前端到後端**（或自訂的一端）保持 **單調遞增或遞減**。它與「一般 FIFO 佇列」不同，也與 [Heap](Heap.md) 的全域排序不同，而是為 **固定長度滑動窗口** 量身打造的結構。

### 特性

| 特性 | 說明 |
|------|------|
| **單調性** | 常見為 **單調遞減 deque** 求窗口最大值（隊首永遠是區間最大候選）；求最小值則用 **單調遞增 deque** |
| **雙端操作** | 新元素從 **後端** 入隊時，自 **後端** 移除「不可能成為窗口最值」的舊候選；窗口滑動時從 **前端** 移除 **已過期**（超出左邊界）的索引 |
| **均攤線性** | 每個下標 **最多入隊一次、出隊一次**，掃完整個陣列通常 **O(n)** |
| **與單調堆疊** | [Stack](Stack.md) 的單調堆疊多處理「下一個更大／更小」；單調 deque 多處理 **區間最值隨窗口滑動**，需同時維護 **時間／下標過期** |

### 常見變化

| 變化 | 思路簡述 |
|------|----------|
| **固定窗口 k 的最大值** | `deque` 存 **索引**，值由大至小單調；右端擴張時從後端 pop 較小值；左端過期索引若等於隊首則 pop_front |
| **固定窗口最小值** | 改為值由小至大單調遞增 |
| **可變窗口** | 若題目仍要區間極值，可與雙指標搭配；單調 deque 仍負責極值查詢 |

### 使用情境

| 情境 | 說明 |
|------|------|
| **滑動窗口最大／最小值** | 每步 O(1) 取得當前窗口極值，整體 O(n) |
| **限制條件子陣列** | 與雙指標結合時，極值結構可加速檢查 |
| **需與 Heap 區分** | **堆**適合「隨時取全域第 k」或 **動態插入** 且窗口語意較弱；**單調 deque** 適合 **窗口連續滑動、僅需區間頭尾極值** |

更多與「窗口」技巧的整合可見 [Sliding Window](../Techniques/SlidingWindow.md)。

---

## 四、使用情境

| 情境 | 說明 |
|------|------|
| **BFS** | 依層級擴展，下一輪頂點先入隊 |
| **排程** | 公平輪詢、工作佇列（先來先做） |
| **多執行緒** | 訊息佇列、任務緩衝 |
| **輔助滑動窗口** | 一般 queue 或 **單調 deque**（見 **第三節**）維護候選索引 |

---

## 五、適合搭配的演算法與題型

| 類型 | 範例 |
|------|------|
| 圖論 | [BFS](../Graph/BFS.md)、最短路徑（邊權相同時） |
| 樹 | 層序走訪（Level-order traversal） |
| 滑動窗口 | 單調 deque 求區間最大／最小（見 **第三節**、[Sliding Window](../Techniques/SlidingWindow.md)） |

---

## 六、小結

佇列適合「依到達順序公平處理」與 **廣度優先** 類問題；若每次要取 **全域最小／最大**，應改用 [Heap](Heap.md) 實作的優先佇列。**滑動窗口內的區間極值** 則優先想到 **第三節** 的單調雙端佇列，並與 [Stack](Stack.md) 的單調堆疊區分使用場景。
