# Hash Map（雜湊映射）資料結構詳解

> **延伸閱讀**：雜湊函數、碰撞處理、Two Sum 等題型的步驟與範例，請見 [Hash Table 演算法詳解](../Search/HashTable.md)。

---

## 一、定義與特性

**Hash Map**（亦稱 **Dictionary**、**Associative Array**）是一種以 **鍵（key）—值（value）** 成對儲存的抽象資料型別。透過雜湊表實作時，在平均情況下可依 key 在近似 **O(1)** 時間完成查詢、插入與刪除。

核心特性：

| 特性 | 說明 |
|------|------|
| **鍵唯一** | 同一 Map 內每個 key 通常只對應一個 value（後寫可覆寫先寫） |
| **無序（常見）** | 多數語言的 `HashMap` 不保證迭代順序；若需依插入序或鍵序，需用 `LinkedHashMap`、有序 Map 等 |
| **值語意** | value 可為計數、索引、巢狀結構等，依題目設計 |

---

## 二、核心操作與複雜度

| 操作 | 平均時間 | 備註 |
|------|----------|------|
| 依 key 查詢 | O(1) | 最壞可能 O(n)，見 Hash Table 文 |
| 插入 / 更新 | O(1) | |
| 刪除 | O(1) | |
| 遍歷全部鍵值對 | O(n) | |

---

## 三、使用情境

| 情境 | 說明 |
|------|------|
| **計數** | 字元／元素出現次數；key 為元素，value 為次數 |
| **索引映射** | 由「值」反查「第一次出現的索引」等 |
| **快取** | key 為查詢參數，value 為計算結果 |
| **分組** | key 為分組依據（如排序後的字串、餘數），value 為清單 |
| **與 Set 搭配** | 只需「是否出現過」時用 Set；需附帶資訊時用 Map |

### Map vs Set vs 陣列

| 結構 | 何時用 |
|------|--------|
| **陣列** | 索引為連續整數 0…n−1，且範圍不大時可直接當桶 |
| **Set** | 只要存在性、去重，不需要 value |
| **Map** | 需要「key → value」語意（計數、索引、任意標註） |

## 四、適合搭配的演算法與題型

以下與 [Hash Table 演算法詳解](../Search/HashTable.md) 重疊處以該文為主，此處列常見對應：

| 方向 | 範例題型／演算法 |
|------|------------------|
| 一次掃描 + 互補 | Two Sum（值 → 索引） |
| 字串／陣列分組 | Group Anagrams（簽章當 key） |
| 頻率與前綴 | 子陣列和為 k（前綴和 → 次數）、Top K Frequent（常搭配 Heap，見 [Heap](Heap.md)） |
| 滑動窗口輔助 | 窗口內字元計數（Map 維護頻率） |

---

## 五、小結

Hash Map 適合「依某個 key 快速帶出 value」的建模；實作細節與雜湊理論請搭配 [Hash Table](../Search/HashTable.md) 閱讀。若題目需要 **前 K 名** 且 n 很大，可考慮 **Map 計數 + Heap** 或 **分桶**。
