# Stack（堆疊）資料結構詳解

> **延伸閱讀**：圖的深度優先走訪與遞迴／顯式堆疊的關係，請見 [DFS 演算法詳解](../Graph/DFS.md)。

---

## 一、定義與特性

**Stack（堆疊）** 是一種 **後進先出（LIFO, Last-In-First-Out）** 的線性結構。僅能在同一端（通常稱為 **頂端**）進行 push（推入）與 pop（彈出）。

核心特性：

| 特性 | 說明 |
|------|------|
| **LIFO** | 最後放入的元素最先被取出 |
| **受限介面** | 通常只允許存取頂端，不支援任意位置 O(1) 刪除 |
| **實作** | 可用陣列（動態容量）或鏈結串列 |

---

## 二、核心操作與複雜度

| 操作 | 時間 | 說明 |
|------|------|------|
| push | O(1) 均攤 | 將元素放到頂端 |
| pop | O(1) | 移除並回傳頂端 |
| peek / top | O(1) | 僅檢視頂端 |
| 是否為空 | O(1) | |

空間：儲存 n 個元素為 **O(n)**。

---

## 三、單調堆疊（Monotonic Stack）

**單調堆疊**不是另一種 STL 型別，而是在解題時 **刻意維護「由底到頂」單調性** 的堆疊用法：常見為 **單調遞增**（底小頂大）或 **單調遞減**（底大頂小），依題目要問的是「左側第一個更大／更小」或「右側下一個更大／更小」來選擇。

### 特性

| 特性 | 說明 |
|------|------|
| **單調性** | 堆疊內元素由底至頂保持約定順序（遞增或遞減）；新元素入疊前，先 **持續 pop** 頂端直到不違反單調性 |
| **均攤線性** | 每個元素 **最多入疊一次、出疊一次**，整段掃描常為 **O(n)** |
| **空間** | 最壞 O(n)（例如輸入遞減時，遞增堆疊可能一次只留一個） |
| **與一般堆疊** | 介面仍是 push／pop；差別在 **入疊前的彈出規則**，用來丟棄「不可能成為答案」的候選 |

### 常見變化

| 變化 | 思路簡述 |
|------|----------|
| **下一個更大元素** | 通常用 **單調遞減堆疊**（較大者在下）；掃到新值時，被 pop 者即找到「右側第一個更大」 |
| **下一個更小元素** | 改為 **單調遞增堆疊**，對稱處理 |
| **含相同值** | 需決定是否嚴格單調（嚴格遞減 vs 非嚴格），避免無限彈或漏算 |
| **二維／柱狀圖** | 例如最大矩形，可在高度陣列上配合單調堆疊求左右邊界 |

### 使用情境

| 情境 | 說明 |
|------|------|
| **Next Greater / Smaller** | 對每個位置找第一個右側（或左側）更大／更小值 |
| **溫度、股價等待天數** | 見「下一個更大」；LeetCode 739（Daily Temperatures）類型 |
| **直方圖最大矩形** | 以高度維護單調堆疊，在 pop 時計算以該柱為高的寬度 |
| **接雨水（輔助）** | 可與雙指標或堆疊解；堆疊版用單調性處理凹槽 |

與 **單調雙端佇列** 的對照：單調堆疊適合「只往一方向掃、問左右鄰接關係」；**滑動窗口最值** 通常改用 [Queue](Queue.md) **第三節** 的 **單調 deque**（可從前端丟棄過期索引）。

---

## 四、使用情境

| 情境 | 說明 |
|------|------|
| **括號／標籤匹配** | 遇左符號 push，遇右符號與頂端比對 |
| **路徑與回溯** | DFS、迷宮、還原路徑 |
| **撤銷（Undo）** | 操作歷程以堆疊記錄 |
| **語法／表達式** | 後序運算、中序轉後序 |
| **單調堆疊** | 見 **第三節**；維護遞增／遞減性，求下一個更大／更小等 |

---

## 五、適合搭配的演算法與題型

| 類型 | 範例 |
|------|------|
| 經典 | Valid Parentheses（括號合法） |
| 單調堆疊 | Daily Temperatures、Next Greater Element |
| 圖論 | [DFS](../Graph/DFS.md)（遞迴隱含呼叫堆疊，或顯式 `Stack<int>`） |
| 樹 | 二元樹前／中／後序走訪的迭代版 |

與 **Queue** 的對照：Stack 處理「先處理最近子問題」；廣度優先則用 [Queue](Queue.md)。

## 六、小結

堆疊適合「暫存尚未完成、需依相反順序處理」的情境。圖論中深度優先與堆疊／遞迴密切相關，可與 [DFS](../Graph/DFS.md) 一併學習。
