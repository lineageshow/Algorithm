# Insertion Sort 演算法詳解

## 一、什麼是 Insertion Sort？

**Insertion Sort（插入排序）** 是一種簡單的**比較排序**演算法。  
核心想法是：將陣列視為「已排序區」與「未排序區」，每次從未排序區取出第一個元素，插入到已排序區的正確位置，重複直到未排序區為空。Insertion Sort 是**穩定排序**（實作上在相等時不左移即可）。

---

## 二、演算法原理

### 基本概念

1. **已排序區**：一開始只有第一個元素（或視為空，從第二個開始插入）。
2. **未排序區**：其餘元素依序處理。
3. **插入**：將當前元素與已排序區由右向左比較，較大者往右移，騰出空位後放入當前元素。

### 執行步驟

1. 若陣列長度 ≤ 1，直接回傳（已排序）。
2. 令 `i` 從 `1` 掃到陣列尾端，`current = nums[i]`。
3. 令 `j = i - 1`，當 `j >= 0` 且 `nums[j] > current` 時，將 `nums[j]` 複製到 `nums[j + 1]`，並 `j--`。
4. 將 `current` 寫入 `nums[j + 1]`。
5. 重複步驟 2～4，直到整個陣列有序。

### 範例

陣列 `[5, 2, 4, 6, 1, 3]`：

- `i=1`：插入 `2` → `[2, 5, 4, 6, 1, 3]`
- `i=2`：插入 `4` → `[2, 4, 5, 6, 1, 3]`
- `i=3`：插入 `6` → 已在位 → `[2, 4, 5, 6, 1, 3]`
- 依此類推，最終 `[1, 2, 3, 4, 5, 6]`

## 三、使用情境

適合以下情境：

| 情境 | 說明 |
|------|------|
| 資料量小 | 常數因子小，實作簡單，小陣列可能比 O(n log n) 演算法更快 |
| 近乎已排序 | 內層移動少，接近 **O(n)** |
| 串流／線上插入 | 新元素插入已排序結構時概念一致 |
| 教學與面試 | 邏輯直觀，易手寫 |

### 常見題型

1. **LeetCode 912**: Sort an Array（資料量大時插入排序可能超時，僅作練習）
2. **LeetCode 147**: Insertion Sort List（鏈結串列版）
3. **子程序**：Timsort、Shell Sort 等會混合使用插入排序處理小段

---

## 四、時間複雜度

- **最佳**：O(n)（已近乎有序，內層 while 幾乎不執行）
- **平均**：O(n²)
- **最壞**：O(n²)（例如遞減陣列）

---

## 五、空間複雜度

- **空間複雜度**：O(1)（原地排序，僅需若干變數）
- 若採用複製到新陣列的實作則為 O(n)，一般面試與教材以原地為主。

---

## 六、與其他排序的比較

| 演算法 | 時間複雜度 | 空間複雜度 | 適用條件 |
|--------|------------|------------|----------|
| Insertion Sort | O(n²) 平均／最壞；O(n) 最佳 | O(1) | 小資料、近乎有序 |
| Merge Sort | O(n log n) | O(n) | 一般陣列、需穩定排序 |
| Quick Sort | O(n log n) 平均 / O(n²) 最壞 | O(log n) | 一般陣列 |
| Cyclic Sort | O(n) | O(1) | 元素為 1～n 且不重複 |

---

## 七、總結

Insertion Sort 實作簡單、原地 O(1) 空間、穩定，在**小陣列或近乎有序**時表現佳；資料量大時 O(n²) 不適合作為主要排序。許多語言標準函式庫的混合排序（如 Timsort）會在子陣列夠小時改用插入排序以減少開銷。
